# Lutils

A collection of utilities and mini-libraries, for Lua by Lua.

I started working on this mainly as a way for me to explore different topics I've read
about and found interesting.

Some of these are experimental, and none of them have a guarantee of safety.
There may be one or two that were originally made for use with [redbean](https://redbean.dev/),
which may cause problems when using one of these files with a standard Lua runtime.
Although they're packaged together here as one library, they're designed to be completely modular.

All of this said, I generally try to keep each lutil bug-free, performant, and easy to use.
If you use any of them in your project, I'd appreciate it if you let me know :)
